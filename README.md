# РусРесурс — сайт кадрового агентства

Многостраничный статический сайт для ООО «РусРесурс»: аутсорсинг и аутстаффинг рабочего персонала в Калининграде и области.

**Живая версия:** [real1zator.github.io/rusresurs-site](https://real1zator.github.io/rusresurs-site/)

Сайт собран без фреймворков и базы данных: HTML, CSS и чистый JavaScript. Открывается локально двойным кликом по `dist/index.html`, разворачивается на любом статическом хостинге.

## Что внутри

20 страниц:

- `index.html` — главная: оффер, услуги, этапы запуска, отрасли, персонал, гарантии, кейсы, отзывы, калькулятор, FAQ, блог;
- `services.html` — сравнение аутсорсинга и аутстаффинга;
- `outsourcing.html`, `outstaffing.html` — отдельные страницы услуг;
- `industries.html` — шесть отраслей;
- `personnel.html` — 16 профессий с фильтрами и поиском;
- `prices.html` — ставки и полный калькулятор смены;
- `about.html` — история, цифры, документы;
- `vacancies.html` — вакансии для соискателей с откликом;
- `reviews.html` — кейсы и отзывы;
- `blog.html` + 5 статей (`blog-*.html`);
- `faq.html` — 15 вопросов в четырёх группах;
- `contacts.html` — контакты, карта, форма, реквизиты;
- `privacy.html` — политика конфиденциальности;
- `404.html`.

Динамика на клиенте: фильтры и поиск по персоналу, вакансиям и блогу, калькулятор с сохранением введённых значений, модальные формы с валидацией и маской телефона, слайдер отзывов, аккордеон FAQ, оглавление статей, мобильное меню и липкая шапка.

## Как запустить

Нужен Node.js 18+.

```bash
npm run build      # собрать dist/
npm run serve      # локальный сервер на http://127.0.0.1:4321
```

Либо просто откройте `dist/index.html` в браузере — все ссылки относительные, сайт работает без сервера.

`build.mjs` собирает страницы из `src/pages`, подставляет общие блоки из `src/layout`, вставляет данные из `src/data`, копирует шрифты, стили, скрипты и изображения в `dist/`. Никаких зависимостей устанавливать не нужно.

## Где что менять

### Контакты и реквизиты

Файл `src/data/site.json`:

- `phoneDisplay` / `phoneHref` — телефон (сейчас заглушка `+7 (4012) 00-00-00`);
- `email`, `whatsapp`, `telegram`;
- `addressFull`, `addressShort`, `hours`, `hoursNote`;
- `inn`, `ogrn` — сейчас «по запросу»;
- `url` — адрес сайта для canonical, Open Graph и sitemap (сейчас Pages: `https://real1zator.github.io/rusresurs-site`). При переезде на свой домен поменяйте здесь и пересоберите сайт;
- `stats` — цифры для доверия.

После правки — `npm run build`.

### Персонал и ставки

`src/data/professions.json`: название, категория, ставка за час, минимальный заказ, теги, описание. Ставка автоматически пересчитывается в смены 8 и 12 часов в таблице на страницах «Цены» и «Аутсорсинг».

### Вакансии

`src/data/vacancies.json`: профессия, оплата за смену, город, график, тип, требования, признак «Срочно».

### Кейсы, отзывы, FAQ

- `src/data/cases.json` — цифры, названия кейсов, описания, фото;
- `src/data/reviews.json` — цитаты, роли, тип проекта;
- `src/data/faq.json` — группы вопросов и ответы.

### Блог

- `src/data/articles.json` — заголовок, категория, дата, время чтения, обложка, анонс;
- `src/articles/<slug>.html` — тело статьи: только `<p>`, `<h2>`, `<h3>`, списки, таблицы, цитаты. Обложка подхватывается из данных.

### Тексты страниц

`src/pages/*.html` — содержимое без шапки и подвала. Общие блоки и подстановки:

- `{{PROFESSIONS_6}}`, `{{PROFESSIONS_FULL}}`, `{{RATES_TABLE}}`, `{{VACANCIES}}`, `{{FAQ_FULL}}`, `{{BLOG_ALL}}` и другие токены описаны в `build.mjs`;
- `data-open-order` на кнопке открывает модальную форму заявки;
- `data-order data-profession="Грузчик"` открывает форму с выбранной профессией;
- `data-vacancy` на кнопке открывает отклик на вакансию.

### Изображения

`src/img/*.jpg`. Замените на реальные фото производства, склада и людей. Рекомендуемый размер — 1600×1067 или 1600×900, вес до 250 КБ. Файлы с этими именами используются в разметке.

Сейчас стоят фотографии Pexels (бесплатная лицензия) как заглушки. Перед публикацией лучше заменить их на собственные снимки — это заметно повышает доверие.

## Что обязательно проверить перед публикацией

Сайт сделан как готовый каркас, но часть данных — демонстрационная. Замените:

1. **Телефон, email, мессенджеры** — сейчас заглушки.
2. **ИНН, ОГРН, юридический адрес** — в `site.json` и на странице контактов.
3. **Домен** — `site.url` уже указывает на GitHub Pages. При подключении своего домена поменяйте значение и пересоберите сайт.
4. **Ставки** — цифры в `professions.json` ориентировочные для Калининграда. Проверьте перед публикацией.
5. **Зарплаты в вакансиях** — демонстрационные.
6. **Кейсы, отзывы и цифры** — «120 человек», «3 часа на замену», цитаты и имена ролей. Замените на реальные или уберите. Фраза о подтверждении отзывов предполагает, что отзывы настоящие.
7. **Срок «24 часа»** — маркетинговое обещание. Оставьте, только если реально успеваете.
8. **Лицензия** — формулировка «лицензированное кадровое агентство» должна соответствовать документам.
9. **Политика конфиденциальности** — шаблон. Проверьте у юриста, добавьте реальные реквизиты оператора и сроки хранения.
10. **История компании** — годы и этапы в `about.html` демонстрационные, замените фактами.

## Формы

Формы работают в демо-режиме: валидация, маска телефона и экран «Заявка принята» есть, но данные никуда не отправляются. Варианты подключения:

- Telegram-бот через небольшой серверный прокси;
- Formspree / Getform / другой form-сервис;
- почтовый скрипт на хостинге.

Точка подключения — обработчик `submit` в `src/assets/js/main.js` (функция `bindOrderForm`). Заявка уже собирается из полей формы, включая расчёт калькулятора в комментарии.

## Дизайн-система

- Палитра: графитово-синий `#0B1B2D`, бумага `#F3EFE6`, медь `#9C4F24`, светлая медь `#C87A43`.
- Шрифты: Oranienbaum (заголовки, цифры), Golos Text (текст, интерфейс). Лежат локально в `src/fonts`, подключаются через `src/assets/css/fonts.css`.
- Сетка: контейнер 1240 px, секции 68–124 px, тонкие линии, нумерация разделов как в документе.
- Анимации: появление блоков при скролле, медленный зум фото, отклик карточек, счётчики цифр. В первом экране — живой печатный портрет: полутоновые точки собираются в изображение, пульсируют, реагируют на курсор, а раз в несколько секунд по нему проходит «скан-линия». Всё уважает `prefers-reduced-motion` (при отключённом движении показывается статичное фото).
- Все размеры и цвета — в CSS-переменных в начале `src/assets/css/main.css`.

## Деплой на GitHub Pages

Сайт опубликован на GitHub Pages и собирается из ветки `gh-pages`: в её корне лежит содержимое `dist/` и файл `.nojekyll`.

После правок достаточно одной команды:

```bash
npm run deploy
```

Она пересобирает сайт, копирует `dist/` во временную папку и обновляет ветку `gh-pages`. Через минуту изменения появятся по адресу [real1zator.github.io/rusresurs-site](https://real1zator.github.io/rusresurs-site/).

Почему не GitHub Actions: на аккаунте сейчас ограничены Actions (billing issue), поэтому выбран деплой из ветки. Когда ограничение снимут, можно вернуть workflow из истории коммитов.

Для другого хостинга: загрузите содержимое `dist/` на Timeweb, reg.ru, Netlify, Vercel или Cloudflare Pages, включите HTTPS. Страница ошибки — `404.html`: в nginx `error_page 404 /404.html;`, в Netlify редирект `/* /404.html 200`.

## Структура

```
build.mjs              сборщик
scripts/serve.mjs      локальный сервер
scripts/publish-pages.mjs  публикация собранного сайта в ветку gh-pages
src/
  data/                контакты, профессии, вакансии, кейсы, отзывы, FAQ, статьи
  layout/              base, шапка, подвал
  pages/               страницы и шаблон статьи
  articles/            тексты статей
  assets/css/          стили и шрифты
  assets/js/           main.js, calculator.js
  fonts/               woff2
  img/                 изображения
dist/                  готовый сайт
```
